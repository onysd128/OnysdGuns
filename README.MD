# Onysd Guns
![Minecraft](https://shorturl.at/LiBIk)<br><br>
👋 Hi! It's my unofficial continuation of MrCrayfish's Gun Mod.  
🏗️ Here I'm fixing issues, creating new content and developing new features.  
📝 I plan to maintain mod only for 1.12.2 version of Minecraft. Don't ask for another versions ;)  
🤯 I'm open for new ideas and suggestions, so don't afraid to contact me!

⚠️ Important: This mod requires **[Obfuscate](https://www.curseforge.com/minecraft/mc-mods/obfuscate)** library to work!

🌐 Also check original mod from MrCrayfish [here](https://github.com/MrCrayfish/MrCrayfishGunMod).

# Full Changes List

### v1.2

1. 🎯 **New Attachments from 1.19** - Ported 3 scopes (short, medium, long), a silencer, 3 stocks (light, tactical, weighted) and 2 grips (light, specialised), each with real gameplay modifiers (accuracy, recoil, reload speed, etc.) and dedicated cock sounds.
2. 🔫 **New Weapon: Heavy Rifle** - Ported model, textures, sounds, stats and workbench recipe from 1.19, added to the creative tab.
3. ⚖️ **Weapon Balance Parity with 1.19** - Updated fire rate, damage, reload amount, recoil and spread for the assault rifle, pistol, rifle, shotgun, machine pistol, bazooka, chain gun and grenade launcher.
4. 🎬 **New Movement Animations** - Ported recoil, sway and bobbing from 1.19 for much smoother weapon handling.
5. 💥 **Reworked Muzzle Flash** - New texture, per-weapon scale, and random variation on every shot.
6. 🔭 **Reworked Scopes** - New reticle textures (holo, red dot, long scope) aligned to the 1.19 scope tube, with an enlarged and tinted medium scope reticle.
7. 🎨 **Restored Dyeable Parts** - Tintindex (dye) support is back on weapons and attachments.
8. 📋 **New Tooltips** - Weapons and attachments now show tooltips matching 1.19.
9. 🗂️ **Creative Tab Reorder** - Items sorted to match the 1.19 registration order.
10. 🔊 **Updated Sounds** - Added cock sounds for every weapon, silenced fire variants, a grenade pin sound, and an attachment UI sound.
11. 🐛 **Bug Fixes** - Fixed a crash when firing a gun with no scope attached, first-person weapon/arms getting stuck yawing sideways, growing sideways drift while bobbing, bullet trails smearing across the screen, and the stun grenade's model shape.
12. 🌍 **Translation Updates** - en/fr/it/uk localization updated for all new content.

### v1.1 (hotfix)

1. 🐴 **Fixed Interaction Bug** - Holding a weapon no longer breaks interaction with horses, minecarts and boats.

### v1.0

1. 🎯 **New Attachment System** - Backported attachment system from newer mod versions! Attach scopes and silencers via a GUI menu (press 'Z' key while holding a weapon). No more workbench required for attachments!
2. 📦 **Creative Tab Changes** - Reorganized the creative tab with a logical order: Workbench, Scopes, Silencer and Parts, Ammunition, Grenades, and all firearms. Changed icon to orange bazooka.
3. 🗑️ **Removed Workbench Recipes** - Old workbench recipes for attaching items have been removed. All attachments are now managed through the attachment menu.
4. 🌍 **Ukrainian Localization** - Added full Ukrainian translation for all items, config options, keybinds, and GUI elements.
5. 🔧 **Silencer Model Optimization** - Reduced silencer model size for better visual appearance and proper fit on weapons.

**Stay tuned for new updates!**
